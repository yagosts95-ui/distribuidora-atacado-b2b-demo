# MH Digital

Demonstração funcional do canal de pedidos da MH Distribuidora.

## Stack
- React 19
- TypeScript
- Vite
- PWA básica
- Persistência local para carrinho e pedidos demonstrativos

## Rotas
- `/` — experiência do cliente
- `/admin` — painel comercial demonstrativo

## Desenvolvimento
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Saída: `dist/`

## Cloudflare Pages
- Build command: `npm run build`
- Build output directory: `dist`
- Node: 20+

## Observação comercial
Os preços carregados na demonstração são referências da tabela fornecida e devem ser confirmados antes de uso em produção.
